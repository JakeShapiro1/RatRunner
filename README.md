<h2>Description</h2>
<p></p>Rat Runner is a 3D horror game built in Unity where players take on the role of a lab rat escaping the experiments of an evil scientist. The game blends puzzle-solving, stealth, and progression as players traverse dark sewer environments, avoid hostile experimental rats, and collect items to escape. It features a custom upgrade and workbench system, AI-driven enemies that dynamically chase the player through rooms and tunnels, handcrafted levels with original 3D assets, immersive audio, a day-based difficulty system, and a polished UI to support a tense survival experience.</p>
<p>My contributions focused on core AI, progression, and level design systems by implementing enemy pathfinding with Unity’s NavMesh to drive dynamic chase behavior through rooms and tunnels. I designed and built a singleton-based Day Manager to control game progression and scale enemy difficulty over time. I also constructed and iterated on level layouts using 3D assets created by the team's 3D modeler, focusing on navigation flow, tension, and gameplay pacing.</p>
